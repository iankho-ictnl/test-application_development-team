# Security assessments

_Owner: security-officer. Lock this file before you change it (see `RULES.md`); the lock name
is `security-assessments.md`._

Per assessment, newest first: date, type (design review, advisory check, full assessment),
scope, and per finding the severity (Critical, High, Medium, Low), location, risk and required
fix. An advisory check is recorded only when it finds an issue that affects this solution.
Compaction shortens fixed and re-checked findings to one line per assessment; open findings
stay in full.
