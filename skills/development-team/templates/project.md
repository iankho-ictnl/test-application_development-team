## How the team folder works

- `decisions.md` is the **overview**, generated by `check-decisions.ps1 -Build` from the files
  below. Read it first; never edit it.
- Every task, question, decision and requirement is its own small file: `tasks/T-001.md`,
  `questions/Q-001.md`, `decisions/D-001.md`, `requirements/REQ-001.md`. New ones are created
  with `check-decisions.ps1 -New`, which gives the next free number.
- Each role writes its own document: `analysis.md` (analyst), `architecture.md` (architect),
  `design.md` (designer), `testing.md` (tester), `reviews/security-assessments.md` (security
  officer), `reviews/sanity-reviews.md` (sanity agent), `reviews/code-reviews.md` (code reviewer and architect).
- When agents run at the same time, each locks the files it changes (`-Lock`) and releases
  them when done (`-Unlock all`). A locked file is never changed by anyone else.
- `archive/` holds checked copies (`-ok`), damaged copies kept as evidence, and in
  `archive/done/` the finished tasks and closed questions that compaction moved there.
