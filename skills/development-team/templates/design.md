# Design

_Owner: designer (optional). Only in a team with a designer. Lock this file before you change
it (see `RULES.md`)._ Larger files, such as mockups, go in `design/` in the team folder.

## User flows

Mermaid diagrams, one per flow, each linked to its requirement or user story.

## Screens

Per screen: its purpose, layout, components, content, states (empty, loading, error, success)
and interactions, linked to its requirement or user story.

## Design reviews

Per review of the built user interface: date, what was reviewed, and each deviation with its
severity (Blocking, Major, Minor).
