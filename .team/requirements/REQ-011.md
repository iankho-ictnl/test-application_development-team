## Requirement

User interface in Dutch (default) and English; more languages can be added.

## Acceptance criteria

Given a new user, when they open any page, then all texts are Dutch; when they choose English, then all texts are English and the choice persists after sign-in again; adding a language needs only a new `.resx` set and a configuration entry, no code change; no page shows a missing-resource key.
