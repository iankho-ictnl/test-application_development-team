## Requirement

A user can have several roles; the permissions per role are configurable.

## Acceptance criteria

Given a user with roles Staff and Finance, when they sign in, then they have the union of both roles' permissions; when an Admin removes a permission from a role, then the API refuses that action (403) for its members at their next request; the last user with the Users permission cannot be removed.
