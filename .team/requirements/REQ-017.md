## Requirement

Runs with `docker compose up`: PostgreSQL with a volume, the API and the admin frontend.

## Acceptance criteria

Given a clean machine with Docker and a filled `.env`, when `docker compose up` runs, then the database, API and frontend start healthy, the admin can sign in, and after `docker compose down` and `up` the data is still there.
