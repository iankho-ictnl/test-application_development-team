## Requirement

In production only the admin frontend is reachable from the internet, over HTTPS with a Let's
Encrypt certificate. The API and the database are reachable only on the internal network. The
public host name is not known yet (Q-035); it is configuration, not code.

## Acceptance criteria

- Given the production compose, when its published ports are listed, then only the reverse
  proxy publishes ports (80 and 443); `web`, `api` and `db` publish none.
- Given a browser on the internet, when it opens `http://<host>`, then it is redirected to
  `https://<host>` and gets a valid Let's Encrypt certificate for that host name; the host name
  is set through one environment variable.
- Given a machine outside the internal network, when it connects to the API or database ports,
  then the connection is refused.
- Given a request through the proxy, when the frontend reads the client address and scheme,
  then it trusts forwarded headers only from the proxy's address.
