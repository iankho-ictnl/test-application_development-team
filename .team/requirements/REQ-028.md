## Requirement

The runtime, libraries and developer tooling stay on supported versions (approved afterwards for D-012, D-018, D-020; Q-071, Q-073, Q-074)

## Acceptance criteria

Recorded by the architect on 2026-11-11 (T-065) from Q-070 to Q-074; the user still confirms them.
- Given the solution, when it is built, then every project targets a .NET release in Microsoft support (now `net10.0`, LTS until 2028-11-14) and `global.json` selects no preview SDK.
- Given a package restore, when NuGet audits the direct and transitive packages, then no known vulnerability is reported and none is suppressed.
- Given the package references, `wwwroot/lib` and the container images, then none is a preview, unlisted or deprecated version, except the test framework xUnit 2 (`xunit` 2.x), which the user chose to keep (Q-070, D-019 rejected).
- Given the Technology versions table in architecture.md, then every row names the version, its end of support and its source, and the upgrade plan moves every part before its end of support (the next .NET LTS before 2028-11-14).
