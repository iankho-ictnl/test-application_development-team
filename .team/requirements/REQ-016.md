## Requirement

Only free/open-source libraries; no extra budget.

## Acceptance criteria

Given the package list (`dotnet list package --include-transitive` and `wwwroot/lib`), when the license of each package is checked, then every license is free for commercial use without paying (MIT, Apache-2.0, BSD, PostgreSQL or similar; no AGPL, no paid license).
