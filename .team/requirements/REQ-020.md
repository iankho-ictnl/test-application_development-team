## Requirement

Secrets (database password, seed admin password, JWT signing key) via environment variables, never in source.

## Acceptance criteria

Given the repository, when it is scanned for secrets, then no password or key is found in source, `appsettings*.json` or compose files (only `.env.example` placeholders); when a required secret variable is missing, then the API refuses to start in Production with a clear message.
