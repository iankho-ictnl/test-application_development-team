## Requirement

Authorization enforced server-side on every endpoint; owner data filtered by OwnerId in every query.

## Acceptance criteria

Given any API endpoint except sign-in, when called without a valid token, then 401; when called without the required permission, then 403; an automated test enumerates all endpoints and fails if one has no policy; given an owner user, when they request another owner's asset, invoice or data, then 404 and nothing is returned.
