## Requirement

Two-factor sign-in is optional per user; an Admin can see and reset it.

## Acceptance criteria

Given a user without 2FA, when they sign in, then a password suffices; given a user with 2FA on, when they sign in, then a valid TOTP or unused recovery code is required and a code is refused after 5 minutes or second use; an Admin sees per user whether 2FA is on and can reset it, after which the user's existing sessions end.
