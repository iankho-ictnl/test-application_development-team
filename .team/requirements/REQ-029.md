## Requirement

The API is described by an OpenAPI document; Swagger UI only in development (approved afterwards for D-016; Q-072)

## Acceptance criteria

Recorded by the architect on 2026-11-11 (T-065) from Q-072 and D-016; the user still confirms them.
- Given the API in the Development environment, when `GET /openapi/v1.json` is called, then it returns 200 with an OpenAPI document generated by Microsoft.AspNetCore.OpenApi that lists every `/api/v1` endpoint, and `/swagger` shows Swagger UI for that document.
- Given the API in the Production environment (any environment other than Development), when `/openapi/v1.json` or `/swagger` is called, then both return 404 (S-8, S-30 in T-047).
- Given the endpoint enumeration test (T6), then neither the OpenAPI document nor Swagger UI adds an endpoint without a permission policy in Production.
