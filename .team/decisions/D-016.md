## Decision

Replace Swashbuckle.AspNetCore 6.6.2 with Microsoft.AspNetCore.OpenApi 10.0.14
(`AddOpenApi`, `MapOpenApi`) for the OpenAPI document, and with Swashbuckle.AspNetCore.SwaggerUI
10.3.1 for the user interface (`UseSwaggerUI` pointing at `/openapi/v1.json`). Both stay limited
to the Development environment, as today; the `swagger` launch URL stays.

## Why

the document generator is then part of ASP.NET Core, supported by Microsoft until
2028-11-14, and is what the .NET 10 Web API template uses; Swashbuckle publishes no lifecycle.
Microsoft advises enabling OpenAPI user interfaces in development only (in line with S-8).
Rejected: Swashbuckle.AspNetCore 10.3.1 for both parts (smaller change, but no official
support); Scalar as user interface (a new tool for the team, no benefit).
