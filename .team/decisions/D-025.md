## Decision

Test the frontend JavaScript (the culture-aware validation script
`wwwroot/js/validation-culture.js` for Dutch/European numbers and dates, REQ-021) with
Playwright for .NET browser tests in `PropertyAdmin.Tests`, against the running Razor Pages
frontend, in `nl-NL` and `en-US`. No separate JavaScript test toolchain.

## Why

(Text restored by the architect on 2026-11-09, T-027, from the T-023 report and task T-030; the
original text was lost.) The script has no tests; it decides whether forms accept `1.234,56`.
Playwright for .NET is free (REQ-016) and fits the existing xUnit test project. Rejected: a
Node.js test runner such as Jest (second toolchain, still needs a DOM); no tests (REQ-021 not
verifiable). Impact: tester task T-030.

Accepted by the user, 2026-11-09.
