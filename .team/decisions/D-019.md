## Decision

`PropertyAdmin.Tests` targets `net10.0` with `<OutputType>Exe</OutputType>` and uses
xunit.v3 4.0.2, xunit.runner.visualstudio 4.0.1, Microsoft.NET.Test.Sdk 18.11.0 and
coverlet.collector 10.1.0. The integration tests of decision #11 add
Microsoft.AspNetCore.Mvc.Testing 10.0.14 (WebApplicationFactory).

## Why

the `xunit` package (v2) is deprecated on NuGet as "Legacy" (security fixes only; all
further work is in v3). The test project contains no tests yet, so the move costs almost nothing
now. Rejected: xunit 2.9.3, the newest v2, which is also deprecated.
