## Decision

Both Dockerfiles use `mcr.microsoft.com/dotnet/aspnet:10.0-resolute` and
`mcr.microsoft.com/dotnet/sdk:10.0-resolute`. The API image keeps installing `fonts-liberation`;
Ubuntu 26.04 puts the Liberation Sans fonts in the same paths that `FileFontResolver` looks for.
Both images keep running as the non-root `app` user.

## Why

Microsoft ships no Debian images for .NET 10; the default `10.0` tag is Ubuntu 24.04
(standard security maintenance until May 2029), and Ubuntu 26.04 (`resolute`, until May 2031) is
also published for .NET 10. Both outlast .NET 10; 26.04 lasts longest. The OS is named in the tag
so that a change of the default tag cannot change the OS unseen. Rejected: `10.0` or `10.0-noble`
(shorter OS support); Alpine and Azure Linux (other C library or package manager, the font install
must be redone, no benefit here); chiseled images (no package manager, so the fonts must be copied
in; possible later hardening step).
