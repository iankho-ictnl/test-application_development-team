## Decision

a user can have several roles; permissions are API policies following the
authorization matrix; roles seeded at start-up; the frontend only hides menu items, the API
enforces; role changes take effect at the next sign-in.

## Why

multiple roles (question 12) and configurable permissions (question 15); S-10
accepted.
