## Decision

Keep `JwtSecurityTokenHandler` and reference System.IdentityModel.Tokens.Jwt 8.23.0
explicitly in `PropertyAdmin.Api` and in the admin frontend, so both use the newest patch. How
tokens are created, signed (HMAC SHA-256 with a key of at least 256 bits, S-7) and validated does
not change.

## Why

7.1.2 is deprecated on NuGet ("Legacy") and the 7.x line ends with .NET 8 on 2026-11-10;
8.x is the active line, supported together with .NET 10. JwtBearer 10.0.14 alone would bring only
8.19.2. Rejected: switching to `JsonWebTokenHandler` (Microsoft.IdentityModel.JsonWebTokens), which
the JwtBearer middleware already uses for validation since ASP.NET Core 8. Same version and same
support, but it rewrites token creation, the two-factor challenge check and the token reading in
the frontend, all security-sensitive, without a support benefit. It can be a later decision.
