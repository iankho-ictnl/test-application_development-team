## Decision

`PropertyAdmin.Api` holds all business logic and is the only component that
accesses the database; `PropertyAdmin.Contracts` holds the shared DTOs; the Razor Pages
project is the admin frontend and calls the API; everything runs in docker compose.

## Why

the user asked for a database, an admin frontend and an API layer for data retrieval
and business logic, with a customer frontend later (question 10).
