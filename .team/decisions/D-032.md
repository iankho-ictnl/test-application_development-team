## Decision

Invoice PDF rendering lives in the Logic project (V1/Invoices/GetPdf), with the PDFsharp-MigraDoc package.
The renderer (`IInvoicePdfRenderer`), `CompanyOptions` (still bound to the `Company` section in
`Program.cs`) and the font resolver move there; PDFsharp-MigraDoc 6.2.4 (D-017) and the
`System.Security.Cryptography.Pkcs` 10.0.14 pin move with it. The API's references go in T-036
together with `Services/`. Same layout, fonts and texts as now.

## Why

The PDF is part of the GetPdf use case: the handler loads the scoped invoice through the service
and renders it, so the controller only returns the file (D-026: thin controller, logic in Logic).
Rejected: keep the renderer in the API project - then the API would need the invoice and owner
models of Logic plus an extra API-side model per PDF, and `Services/` could not be removed in T-036.
