## Decision

The tester writes regression tests for the admin frontend screens (REQ-030; kept by the user,
Q-076): a `WebApplicationFactory` of the frontend in `PropertyAdmin.Tests`, whose API
`HttpClient` is routed to the in-memory API of `ApiFactory`. Per page and role: anonymous is
redirected to sign-in (US-1), allowed roles get 200 with the key content (list rows, form
fields, totals), others get the access-denied page; a save round trip per form. They run in
every normal `dotnet test` run, without Docker (no running stack needed; D-039), and an item is
ready only when they pass. Needs `public partial class Program;` in the
frontend (frontend-developer-1) and an `extern alias` in the test project, because both hosts
have a global `Program`.

## Why

RULES/tester rules: before a restructuring, characterization tests cover every endpoint and the
screens that use them. F4 rewrites the frontend API client of every screen, and there are no
frontend tests at all. Rejected: Playwright browser tests (D-025) for this, because they need a
running stack and are slower; they stay for the JavaScript of D-025. Impact: tester, 3 story
points (T-057). Originally written as characterization tests before F4 (T-037); T-037 was
dropped (D-037) and the tests stay as regression tests (Q-076, Q-080).
