## Decision

Bootstrap 5.1.0 to 5.3.8. jQuery, jQuery Validation and jQuery Validation
Unobtrusive depend on question 22:
- browser-side validation not wanted: remove them from `wwwroot/lib`, `_Layout.cshtml` and
`_ValidationScriptsPartial.cshtml`. Today no page renders `_ValidationScriptsPartial`, no page
script uses jQuery, and Bootstrap 5 does not need jQuery;
- browser-side validation wanted: jQuery 3.7.1, jQuery Validation 1.22.1 and Unobtrusive 4.0.0,
with `_ValidationScriptsPartial` rendered on the form pages.
Validation in the API stays the authority in both cases.

## Why

Bootstrap 5 is "Active LTS" and 5.3.8 is its newest version. jQuery 4.0.0 is the newest
jQuery, but Unobtrusive 4.0.0 (its newest release, part of ASP.NET Core) calls `$.parseJSON` and
`$.isFunction`, which jQuery 4 removed. So jQuery stays on 3.x (critical security fixes only) if
it is kept, until an Unobtrusive release supports jQuery 4. Rejected: jQuery 4 with the jQuery
Migrate plugin kept permanently (jQuery recommends Migrate only as an upgrade aid).
