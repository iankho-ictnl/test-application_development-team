## Decision

Adds to D-011. Every test class or test carries `[Trait("Requirement", "REQ-nnn")]` (or `US-n.n`)
and `[Trait("TestCase", "TC-n")]`; testing.md lists every TC with its trace, and a requirement
without a TC is listed as a gap. Tests mirror `V1/<Feature>/<UseCase>/` with `ApiTests`
(integration), `HandlerTests` and `MappingTests`; `Characterization/` is folded into them by
T-038. A characterization test that fixes behaviour differing from a requirement carries
`[Trait("Differs", "BUG-n")]` and changes with the fix. Tests never depend on data or counts
made by other tests in the shared fixture. Details: testing.md, "Review of the existing tests (T-021)".

## Why

The current tests (69 characterization tests plus the V1 tests of T-033 and T-034) have no trace to a requirement or test case (TC-1 to TC-9 are groups
only), so gaps cannot be seen; several characterization tests fix behaviour that differs from
approved user stories (BUG-1 to BUG-6) without saying so; `Last_user_admin_cannot_lose_the_permission`
depends on no other test creating an Admin. Rejected: naming conventions only (not filterable
with `dotnet test --filter`); a separate trace table only (drifts from the code). Impact: tester,
1 story point, within T-038.
