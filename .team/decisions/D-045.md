## Decision

DELETE /api/v1/owners/{id} (and /api/owners/{id}) sets `Owner.InactiveSince` (nullable `date`) to today through `TimeProvider` and never removes the row (BUG-3, Q-026). A repeat returns 204 and keeps the first date; an unknown id is 404; an owner with assets is still refused (400, US-2.3, BR-1); invoices no longer block. The owner list leaves inactive owners out; get by id still returns them, so invoices keep their owner. Response shapes are unchanged: no interface-contract change. The migration only adds a nullable column (D-024).

## Why

Q-026: owners are only marked inactive; REQ-024 counts the 7-year anonymization term from the date, so a date beats a boolean. Rejected: a boolean `IsActive` (loses the date), and a global EF query filter (would hide the owner of an old invoice and every by-id read).
